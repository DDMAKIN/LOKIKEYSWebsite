# Getting help

- **Orders, keys, activation or refunds:** email **support@lokikeys.com** (Monday to Saturday, 10 AM–7 PM IST). Please don't post order details in GitHub issues.
- **Delivery and refund rules:** see the [Delivery & Refund Policy](public/refund-policy.html).
- **Security problems:** see [SECURITY.md](SECURITY.md). Never report them in a public issue.
- **Bugs or ideas for the website:** open an issue using the templates.
